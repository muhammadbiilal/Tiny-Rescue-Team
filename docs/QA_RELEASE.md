# Acceptance and Production Release Gates

1. 365 missions have playable scene files, unique ID, real tactical choice, at least one validated free-player solution, deterministic replay witness, asset completeness and human QA record. No brief row counts as playable.
2. Twelve responders have original consistent art, readable animation states and implemented abilities; every effect maps to a simulation event. Placeholder art rejected from release.
3. Progression economy has tested non-paying path through 365, no soft lock, no grind requirement that invalidates completion; balance reviewed with real players.
4. Offline first launch, mission play, progress and all content work. Ad SDK disabled/offline failures do not affect gameplay.
5. Unit, widget, integration, device and performance QA logged; no claim of 60 FPS without measurement. Android and iOS release builds signed/tested where available.
6. Art/audio rights, privacy/ads policy, name clearance, store metadata, accessibility and age rating completed. Final publication only with owner authorization.

Use a matrix by mission ID with authored/solver-validated/human-played/art-complete/balanced/release-ready columns. Track counts honestly after each batch. A prototype with one beautiful hero is a vertical slice, not a production-ready 365-mission game.
