# Screens and User Experience

Home/base with animated roster and clear Play; campaign district map; mission preview (objective, hazard, recommended team); roster selection, equipment, placement; mission scene with pause, speed and limited tactical actions; success/fail with explanation and replay; upgrade tree, gear, collection, settings, privacy/support. Onboarding teaches deploy → dispatch → ability → result in first four missions. No long tutorial wall.

Gestures: tap/select, drag placement with tap alternative, ability button, inspect role/hazard, pause/slow. Screen reader alternative presents action log, unit status and selection in semantic order. Text scaling, contrast, reduced motion, color-independent role icons and larger target areas. Mission remains comprehensible without sound. Portrait UI is tentative until 10-mission vertical slice proves camera readability on small screens. Tablet adapts without stretching sprites.

Player feedback: forecast before dispatch, visible reason for blocked action, action icons and readable event log, concise rescue result. Avoid cluttered currencies, popup chains, countdown pressure, paywall and fake interactivity in marketing. Save after each result and key settings change. No account.
