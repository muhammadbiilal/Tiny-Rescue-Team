# Tiny Rescue Team — Heroes Edition

**This package supersedes the earlier Tiny Rescue Team grid-puzzle package.** Working game title remains Tiny Rescue Team. The new direction is an original, character-driven 2D tactical rescue autobattler built with Flutter + Flame: place a team, equip and dispatch it, watch animated units respond, and make a small number of meaningful tactical interventions. It takes inspiration from the polish and depth of character-driven mobile games without copying Idle Horizons or the three puzzle references.

The 365 CSV/JSON rows are editorial mission briefs, not playable scenes. Build them through the production pipeline and record validation. This package contains no finished code, sprites, sound or certified missions.

Read `CLAUDE_MASTER_PROMPT.md`, `GAME_DESIGN.md`, `CHARACTERS_AND_PROGRESSION.md`, `ART_ANIMATION_AUDIO.md`, `MISSION_DESIGN.md`, `TECHNICAL_ARCHITECTURE.md`, `UI_UX.md`, `ADS_PRIVACY_ASO.md`, `QA_RELEASE.md`, then `IMPLEMENTATION_PROGRESS.md`. Copy whole folder to `docs/tiny_rescue_team/` in the Flutter repository, replacing the old brief. Do not combine contradictory old mechanics with this version.
