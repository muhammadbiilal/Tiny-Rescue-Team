# Tiny Rescue Team

Offline character-driven 2D tactical rescue autobattler (Flutter + Flame). Plan a small team, dispatch them, watch deterministic autonomous action, and use a limited ability.

Harbor missions M001–M030, Old Town M031–M060, and Riverside M061–M090 are the current playable districts. The remaining 275 CSV/JSON rows in `docs/` are briefs only.

This is not affiliated with any emergency service and is not real safety training.
